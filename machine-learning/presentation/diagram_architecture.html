SYSTEM ARCHITECTURE

Three programs. Only the middle one is trusted with anything.

1

The browser

What a student sees

Shows the campus map and the chat box. Takes the question, displays the answer, and nothing else.

Holds no keys. Anything shipped to a browser is public, so it is given nothing worth stealing.

ASKS
2

The server

Where every rule lives

Works out what the question is about, gathers the facts, and enforces the privacy rule before anything is sent back.

The only part that can reach the data. If a rule is broken anywhere, it is broken here.

USES
3

The helpers

Storage and models

Database — locations, documents, schedules.
Two small models — one turns text into numbers, one estimates availability.
One language model — writes the final sentence.

None of them decide anything. They are asked, they answer, and the server judges.

The browser can never reach the database or the language model by itself. Every request goes through the server, because that is the only place the privacy rule can be enforced.

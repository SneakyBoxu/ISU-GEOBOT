HOW A QUESTION IS ANSWERED

Five steps, every time. Only step 3 changes depending on what was asked.

1

You ask

Plain English, typed into the chat
“Where is the College of Computing?”  ·  “When does the second semester start?”  ·  “Is SIM-33 free right now?”
2

The system sorts it

One question, answered in 2 ms
Is this about a person? It checks the question against the list of lecturers and a short list of availability words. No AI is used here — a lookup is faster and always gives the same answer.
3

It gathers facts

This is the only step that forks

NOT ABOUT A PERSON

Search the documents — handbook, calendar, building descriptions — and keep the five closest passages.

ABOUT A PERSON

Check the timetable and ask the trained model for an estimate. If the lecturer has not agreed to this, the system does not even calculate it.

4

The AI writes it up

Only the wording, never the facts
The facts gathered in step 3 are handed to the language model, which turns them into a sentence. It is never asked to work out whether someone is available — it is told, and asked to phrase it.
5

A last check

Before anything leaves the server
The answer is scanned for anything it must never contain — a room, a building, a floor, or the model's raw numbers. In our evaluation run it had to stop 0 of 78 answers, because nothing got that far.

Availability comes from the timetable. The AI only writes the sentence. That is the whole design. A language model asked to guess where a lecturer is would answer fluently and be unfalsifiable — so it is never asked.
